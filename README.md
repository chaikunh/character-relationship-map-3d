# STAR WARS 人物相関 3D グラフ

スター・ウォーズ登場人物の関係性を 3D 空間に可視化する、Obsidian のグラフビュー風ビューアです。
Three.js による力学レイアウトで、マウス／タッチで回転・ズーム・移動できます。

## 起動方法

ES Modules を使っているため、`file://` で直接開くと動きません。
ローカル HTTP サーバー経由で開いてください。

```bash
# このフォルダ（index.html がある場所）で
python3 -m http.server 8000
# → ブラウザで http://localhost:8000 を開く
```

Node.js 派なら `npx serve` などでも可。

## 操作

| 操作 | 動き |
|------|------|
| 左ドラッグ | 回転 |
| スクロール | ズーム |
| 右ドラッグ | 平行移動 |
| 球をクリック | 人物を選択（関係先をハイライト） |
| 右リストをクリック | 人物を選択＋カメラがフォーカス |
| 検索ボックス | 名前で絞り込み選択 |
| 画像をドロップ | 写真を球体に貼り付け（貼る人物を選択） |

スマホはタッチで回転、ピンチでズーム。

## よくある編集

- **キャラを追加**: `js/data.js` の `nodes` に 1 行足す。`id` は一意に。
- **関係を追加**: `js/data.js` の `links` に `['idA','idB','タイプ']` を足す。
  タイプは `family / master / ally / enemy / romance`。
- **陣営や関係の色を変える**: `js/data.js` の `FACTION` / `REL`。
- **写真を最初から表示**: `nodes` の各 `image:''` に画像 URL を入れる。

## 写真について

映画スチルや俳優写真など著作権で保護された画像の URL は同梱していません。
ご自身が利用権を持つ画像、またはライセンスが明確な画像を使ってください。
ドラッグ＆ドロップした画像はブラウザ内（メモリ上）で処理され、外部送信はされません。
